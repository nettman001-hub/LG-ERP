# 📖 UniONE AI 확장 프로그램 사용 설명서 (시니어 및 사용자용)

환영합니다! 본 설명서는 **UniONE AI (유니원 AI)** 확장 프로그램의 개념을 이해하고, 다른 환경의 시니어 AI(안티그래비티 등) 또는 사용자가 이 확장 프로그램을 100% 활용하기 위해 작성되었습니다.

---

## 1. 🚀 UniONE AI란 무엇인가요?
**UniONE AI**는 인터넷 연결 없이 사용자의 로컬 환경(Ollama, LM Studio 등)에서 구동되는 **에이전틱 AI 코딩 어시스턴트**입니다. 
단순히 코드를 텍스트로 추천해주는 것을 넘어, 사용자의 승인하에 **파일을 직접 생성/수정/삭제**하고 **터미널 명령어를 실행**하는 능동적인 "부하 직원(주니어 개발자)" 역할을 수행합니다.

## 2. ⚙️ 초기 설정 및 연동 방법
확장 프로그램을 설치한 후 다음 설정을 확인해 주세요.

*   **AI 엔진 연결**: `VS Code 설정(Ctrl+,)` > `UniONE AI`에서 로컬 AI 주소(기본: `http://127.0.0.1:11434`)와 모델명(예: `gemma4:e2b`)을 지정합니다.
*   **Second Brain 연동**: 깃허브 레포지토리 URL을 설정에 기입하면, AI가 해당 저장소의 마크다운 파일들을 읽어 자신의 '글로벌 지식'으로 활용합니다.

## 3. 🧠 핵심 기능 요약
UniONE AI는 내부적으로 **Action Tags(XML 형태의 명령 태그)**를 사용하여 시스템과 직접 소통합니다.

1.  **파일 직접 제어**: 코딩 지시를 내리면, `<create_file>` 및 `<edit_file>` 태그를 이용해 작업 폴더에 코드를 물리적으로 작성합니다.
2.  **터미널 제어**: `<run_command>` 태그를 사용해 `npm install` 등의 터미널 명령을 대신 수행합니다.
3.  **지식의 구조화 (P-Reinforce)**: 외부 지식이 주입되면 AI가 'Architect 모드'로 변환되어, 비정형 데이터를 분석해 `.unione-ai-brain/10_Wiki/` 하위에 마크다운 형태로 깔끔하게 구조화하여 저장합니다.

---

## 4. 🌉 외부 AI와의 하이브리드 협업 (브리지 서버)
이 확장 프로그램의 가장 강력한 기능은 **다른 시니어 AI(예: Antigravity)와 통신하며 협업**할 수 있다는 점입니다.

### 브리지 서버 활성화
*   확장 프로그램이 켜지면 백그라운드에서 **로컬 브리지 서버(포트 4826)**가 자동으로 가동됩니다.
*   이 서버는 외부로부터 코딩 지시나 시험 문제, 지식 데이터(`/api/brain-inject`)를 수신받을 수 있는 API 엔드포인트 역할을 합니다.

### 어떻게 협업하나요? (사용 예시)
1.  사용자가 데스크탑의 메인 AI(안티그래비티)에게 **"@유니원, 로그인 페이지 컴포넌트를 만들어줘"**라고 지시합니다.
2.  메인 AI(시니어)는 자신이 직접 코드를 짜지 않고, 즉시 4826 포트로 해당 지시를 전송합니다.
3.  VS Code 내의 UniONE AI(주니어)가 지시를 수신하여 코드를 무상(무료 토큰)으로 작성합니다.
4.  작성이 완료되면 시니어가 결과를 검토하고 에러가 있다면 다시 주니어에게 수정을 지시하는 **무인 자동화 개발 스튜디오**가 펼쳐집니다.
